# 工程环境内存档案接入清单

工作台已预留按产品实例 ID 查询 `rate:cpp:{产品实例ID}` 的界面、接口契约和适配器边界。当前页面入口只用于人工核对，不作为查询 API。

## 内网需要采集的资料

在内存管理页面使用 `rate:cpp:35772967` 查询，并从浏览器开发者工具 Network 中记录：

1. 查询请求的 URL、HTTP 方法、查询参数和请求体；优先提供脱敏后的“复制为 cURL”。
2. 一份成功响应和一份无匹配响应，保留字段名、嵌套层级及数据类型。
3. 鉴权方式及承载位置，如 Cookie、请求头 Token 或登录前置请求。
4. 查询前是否需要选择集群、租户、分区、命名空间等上下文，以及对应参数。
5. 若响应为二进制或编码字符串，继续记录页面发起的解码请求及其响应。

## 本地配置项

- `ARCHIVE_PAGE_URL`：内存管理页面入口，仅展示。
- `ARCHIVE_API_URL`：真实查询 API，取得内网资料后填写。
- `ARCHIVE_AUTH_TOKEN`：本地鉴权信息，只在 Node 进程内使用。
- `ARCHIVE_TIMEOUT_MS`：查询超时，默认 60000 毫秒。

配置和凭据不进入浏览器存储或接口响应。真实协议确认后，只需实现 `server/archive-service.js` 中的适配器接口，现有页面和 `/api/query/archive` 返回契约保持不变。
